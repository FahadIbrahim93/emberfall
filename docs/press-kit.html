THE UNUSUAL PART

The game's CI plays it. On every push an autopilot bot flies it with real touch inputs. It reaches wave 3, grazes bullets and chains combos, and nothing ships unless that run passes. A test also covers a new player's first minute: ready in under 3.5 seconds, first shot within 2, enemy fire by about 6. Every number on this page comes from a test.
