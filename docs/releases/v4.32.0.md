# EMBERFALL v4.32.0 — "One Simulation"

Released 2026-11-16. Play it at **https://emberfall-game-two.vercel.app/** or on [GitHub Pages](https://fahadibrahim93.github.io/emberfall/).

This is a reliability release. The game you fly is the same as v4.31.0: menus, hangar, Daily, and the feel of a run are unchanged. The work is in the tests, the gates, and the truth of the docs.

## What's new

**One simulation.** The tests no longer keep a second, typed copy of combat and boss logic that the game never imported — that copy had already drifted (0 points and 0 kills against the shipped core's 200 and 4 on the same scenario). `packages/sim` is now a typed facade over the bytes `index.html` executes. The game still plays from `file://` with no compile step.

**Parity is an equality gate.** A per-tick hash chain names the first divergent tick if the shipped core moves. Goldens were re-recorded from that core, on purpose, and no test was deleted or weakened to make them agree. Changing bolt speed in a rehearsal failed the parity suite at tick 95.

**Gates fail out loud.** A derived copy check that finds nothing to inspect is a failure, not a skip. Coverage now prints the denominator next to every percentage. `package.json` states its MIT licence so it agrees with `LICENSE`.

**A Sunday-only test is fixed.** A Daily receipt case that expected a 0 reward used wave 20, which earns Sunday's Solar Guard. That run now stays under every daily threshold.

## Your save

Career saves are unchanged and stay on your device. Back them up from the hangar with an export code. **No database change.** Existing scores, profiles and loadout codes are untouched.

## Under the hood

- Service worker cache `emberfall-v4.69`.
- `npm run typecheck` (`tsc --noEmit`, strict) is part of `check.sh`.
- The release stamp tool now follows the README's `Current release` line, after the title was rewritten in #118.
- **No database change.**

Tests at release: 106 browser, 78 simulation, 58 release and 75 in-game checks, all passing.
